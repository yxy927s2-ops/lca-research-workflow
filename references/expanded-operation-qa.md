# 展开单元操作后的流程图验收

现有绘图规格可能以一个计算过程为一个主节点；当图中按文献工艺图展开内部操作时，科学流可以指向该过程的子操作，而数值仍由原计算过程拥有。验收必须同时检查这两层，不能把子操作误判为新计算过程。

## 建立映射

- 每个子操作有稳定 ID、父计算过程 ID、文献中的出现次数、顺序、简短目的、输入与输出名称及拓扑证据。重复的离心/洗涤等各自占一个节点；不因相同名称合并。目的写在操作框内，输入输出由相连箭头表达，不在框内再列“入/出”。
- 每条定量科学流保留 Excel 的流 ID、数值、单位、原计算过程端点。若连到子操作，则检查该子操作的父过程与 Excel 端点相同。跨过程流的两端分别核对。
- 模块总量没有可证明的操作端点时显示为模块级数值框；其科学流 ID 仍且仅出现一次，不创造多条定量子流。示意性用水点或内部回流必须有独立的拓扑证据，并标明不是新增数量。
- 原文示意图的单元级数值与已采用参数化模型若不属同一情景，只可用于拓扑或在另案中重建，不得混入当前模型图。

## 双层验收

1. **科学层**：工作簿与绘图规格的流 ID、采用值、单位、基准、方法状态一致；没有分配负担和替代收益被画作物理流；同源双重表达（如乳清与废水交换）不重复合计。
2. **展示层**：每个必要操作有简短目的，以及至少一条可追溯的输入和输出箭头；有独立数量的箭头追溯到科学流，没有独立数量的拓扑箭头追溯到工艺证据。箭头实际连接到正确子节点，方向与文献相同；四次离心等重复操作数量一致；模块级数值框不伪装成设备级数值。箭头与标签为两个可单独调整的对象，内部无歧义短主线可不重复写文字。
3. **图面层**：主线尽量对齐直连，折弯仅为分支/回流所需；检查箭头终点、标签与线的留白、文字越框、交叉遮挡、同类框尺寸、图例及三张汇总表。渲染后检查，不能以 JSON 自填 QA 代替。

第十版验证器对科学流、操作间拓扑箭头、模块注释分别核对，并检查子节点父过程和实际端点。人工编辑后先将图元变动回填到展示映射再验收；不能以旧规格通过或忽略报错代替复检，也不得为使脚本通过而删掉来源支持的单元操作。
