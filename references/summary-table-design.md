# 汇总表设计规则

本文件只用于流程图中的输入、输出、能源和平衡汇总。详细公式和来源保留在 Excel；图中表格用于快速阅读，不维护第二套科学事实。

## 1. 真实行列

每个表格由独立标题行、表头行、数据行和可选合计/限制行组成。每列使用统一边界和对齐方式；禁止用空格、全角空格、制表符或手工换行模拟列。

推荐列结构：

| 表格 | 必需列 |
| --- | --- |
| 总输入清单 | 外部物料/水、数值、单位、用途或模块 |
| 总输出清单 | 系统边界输出、数值、单位、性质或说明 |
| 总能源消耗 | 模块、电力（kWh）、热量（MJ） |
| 平衡摘要 | 项目、输入、输出、残差、状态 |

列可以在空间不足时合并“数值 + 单位”，但同一张表必须保持一致。

## 2. 对齐和格式

- 名称和说明左对齐；数值右对齐；单位居中或左对齐；表头按列统一。
- 同一物理量使用统一有效位数。合计显示精度不得高于来源能够支持的精度。
- 数字、小数点和单位不得跨行拆开；长说明优先增加说明列宽。
- 同一层级采用统一行高和单元格内边距；不能通过缩小某一行字体塞入内容。
- 合计行使用较强字重或浅色底纹二选一，避免同时叠加强色、粗边框和粗体。

## 3. 层级与密度

- 表格标题说明范围与计量基础，例如“每 1 kg SPI”。
- 表头与正文至少通过底纹、字重或分隔线中的一种区分。
- 普通数据行避免全部加粗；优先突出最终产品、合计、残差和限制状态。
- 正文下方无信息空白不得超过正文内容高度的约 35%。内容少时缩短表格，内容多时增加高度或拆表，不缩字。
- 表格之间共享标题高度、表头高度、正文行高、圆角和边框强度，避免每张表形成不同视觉系统。

## 4. 语义限制

- 此处“总输入/总输出”指覆盖当前系统边界内全部应计外部物料流的清单，不等于把不同物质的数值相加。逐项核对模型流 ID，内部转移不得重复计入；若覆盖不全，不能冠以“总”字并交付为完整清单。
- 能源表可以分别合计电力和热量，不把 kWh 与 MJ 直接相加。
- 默认图面只放上述三张表；平衡检查保留在 Excel 与审计记录中。用户另要平衡表时才增加，且必须写明 `代数闭合`、`独立验证闭合`、`未闭合` 或 `未核算`；子平衡闭合不得表述为整体闭合。
- 同一流在流程区和表格区使用一致名称、数值、单位和小数位规则。

## 5. 交付检查

- 所有表格具有真实列边界或可辨认的网格列；
- 数值列对齐，单位和精度一致；
- 表头、正文、合计和限制行层级清楚；
- 没有用空格模拟的伪表格；
- 在最终尺寸下无截断、贴边或跨列误读。
