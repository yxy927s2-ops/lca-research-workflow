# Excel 完成后的数据支撑能力汇报

S4.1 汇报和冻结确认（闸门 B） 之前，依据 Excel 的`参数覆盖度矩阵`、`问题与决策`与`待补参数清单`向用户给出明确的能力结论。此汇报是数据解释与绘图功能输入，不是重新选择采用值；绘图功能启动时引用同一结论。不要等成图后才发现精度不够。

## 必答内容

1. **范围与基准**：目标产品、功能单位、系统边界、当前采用的来源文件/代码分支，以及前景与背景接口。
2. **实际数据层级**：分别数清产品系统、计算过程/模块、可辨识单元操作、参数和物理流。逐过程说明数值的拥有层级，不以工艺图中画出设备推断该设备有独立量。
3. **每类流的精度**：标为“操作级直接给出”“可由已采用公式唯一拆出”“只有过程/模块总量”“仅有拓扑或定性描述”“缺失”。对于总水、电、热、物料、排放，逐类列出可用层级和例子。
4. **能画的图及其上限**：明确回答能否做产品系统总览、模块化流程清单、逐单元定性进出料、逐单元定量清单、能耗图或其他图。若操作数量和数值粒度不同，分别陈述；不可用“数据完整”概括。
5. **禁止的推断**：列出不能直接落到某台设备的模块总量、不可混用的原文示意情景与采用模型代表情景、不能当新外部投入的内部回流，以及未连接背景数据库时不能宣称的 LCIA 结果。
6. **绘图功能显示决定**：说明有证据的操作与流可连线；仅有模块总量的流用模块级数值框；操作级用水点可定性标示但不拆总量；能源若公式可拆项，注明是否选择展示。给出一句明确结论，例如“可完成模块定量＋操作拓扑清单，不能完成全操作定量清单”。
7. **问题与待补项**：给出 QC 复查后仍有问题的对象 ID、证据、对流/公式/成图的影响和按操作索引的待补项，及时请用户决定。不设固定复查次数；冻结确认（闸门 B） 的“清单确认”与“准予冻结并进入绘图”分别记录。

## 表述与交接

- 汇报引用 Excel 的过程、参数、流与公式的确切位置；对来自正文、附件图或代码的拓扑证据另列。区分作者原文直接数值、采用公式派生值和绘图解释。
- 核算检查以确认抓取、公式归属、单位与重复计算为重点；记录来源内部差异及影响，不默认把权威文献当审核对象，也不擅改作者参数。
- 用户已经确认的研究口径和数值分支不因进入绘图功能而反复询问。若只有视觉/展示粒度问题，留在绘图功能解决；只有新证据改变科学事实时返回数据功能。
- 若用户要求的定量层级高于来源支持能力，先明确不足及“模块量＋操作拓扑”等忠实表达方式，不虚构分配，也不把缺口标志强塞进正式图。
