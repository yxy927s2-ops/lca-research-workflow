# 乳清案例（wpi-guyomarch2024）：乳清蛋白浓缩液（WPI）前景清单与流程图

第二个端到端金标准案例，与 `spi-siegrist2026` 并列，用于"什么算交付质量"的对照与同类课题（乳制品／多产品线／范式不同处理）的实战参考。数据均来自公开文献。

## 课题与边界

- **功能单位**：1 天生产（原料奶 583 m³/d → WPI 浓缩液 11.7 m³/d），按原文体积基准。
- **系统边界**：cradle-to-gate 到 WPI 浓缩液出厂（含第 10 步 4℃ 100 km 冷藏运输）；PR13–19（α/β 蛋白分离）已整体移出；乳糖回收（PR11–12）、污水站（PR20）保留。
- **建模范式**：课题 CLCA（边际预测），与框架文献（Guyomarc'h 2024，ALCA）范式不同——范式三分类情况③a。放弃文献分配因子（四套 AF 保留候选作对照留档，不进入课题模型，`PA-AF-*`）；边际供应商与副产品替代接口待功能三确定（Q-19，取代 Q-07）。物理流保持分配/替代处理前原貌；不做 LCIA。
- **资本品**：纳入（Machines 段设备／部件级材料按天摊销）。
- **模块划分**：M1 收奶与分离（PR01–04）／ M2 牛奶蛋白分级（PR05–07）／ M3 乳清蛋白浓缩（PR08–10）／ M4 乳糖回收（PR11–12）／ M5 污水处理（PR20）。

## 来源

- **框架来源**：Guyomarc'h 2024 的 DIB 数据集原始记录层（`SRC-RAW` 权威版：20 张步骤表＋Process diagram）；逐流参数表与分配因子见其论文附件（`SRC-PDF`／`SRC-XLSX`）。
- **数据基线纪律**：一手原始文件是唯一直接取数基准；衍生版（`SRC-COMP` 工作底稿／`SRC-MODEL` SimaPro 实现）仅参考，严禁取数为基准。
- **唯一开放项 GB-04**：污水站出水 450 m³/d 为 proxy 参考流，与进水 191.7 m³/d 不对应，使用时按 proxy 口径注明。

## 关键数字（自检基准）

- 生产电力合计（WPI 边界）：25,806.3 kWh/d（含污水站 5,050.7）；清洗电另计 2,084 kWh/d。
- 主流：原料奶 583 → 脱脂奶 525＋稀奶油 58；乳清 350＋透析水 63 → WPI 11.7＋乳糖渗透液 401.3 → 浓缩乳糖 85.3＋渗透水 316。
- WPI 出厂流 FL-O-WPI = 11.7 m³/d（与 FL-WPI 同量，原文无损失报告）。
- 资本品、CIP 清洗剂、NH3 补加逐条在冻结清单，不进图（图注已说明）。

## 与 SPI 案例的差异（为什么值得作为第二个模板）

- 与 SPI 案例同为"文 ALCA→课 CLCA"（范式三分类情况③a）——两案差异在：SPI 边界与文献一致、是绘图管线校准基准；乳清做了边界裁剪（PR13–19 移出）与用户手排版，且多产品线与废水线更复杂。
- 做过**边界裁剪**（PR13–19 移出）与用户边界确认，SPI 边界与文献一致——边界缩小菱形有一个完整走查样本。
- 绘图是"机器底稿＋用户手排版"，**验收图以用户手改版为基准**；同时冻结簿可作机器自动排版路径的回归基准（复跑比对）。
- 多产品线并存（WPI／乳糖／渗透液）＋复杂废水线，回流取舍与分项—总计闭合的判例比 SPI 更全。
